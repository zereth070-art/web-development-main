# Proyecto final DAW

## Idea

Construir una aplicación web completa con frontend, backend, base de datos, autenticación y despliegue.

## Requisitos mínimos

- Página pública.
- Registro e inicio de sesión.
- Roles o permisos.
- CRUD principal.
- Validaciones.
- Base de datos relacional.
- API documentada.
- Interfaz responsive.
- Despliegue.
- README profesional.

## Ideas

- Gestor de tareas para equipos.
- App de reservas.
- Inventario para pequeño negocio.
- Plataforma de eventos.
- Gestor de hábitos.
- Biblioteca personal.

## Evaluación

- Código organizado.
- Seguridad básica.
- Experiencia de usuario.
- Correcto uso de base de datos.
- Despliegue funcional.
- Documentación clara.
